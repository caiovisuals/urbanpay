# CONTRIBUIÇÃO

Obrigado por considerar contribuir com o Urbanpay. Este projeto evoluiu para um monorepo que engloba aplicações web (Next.js) e mobile (React Native), além de possíveis pacotes compartilhados. O objetivo é manter uma base organizada, escalável e próxima de um ambiente real de fintech.

## Diretrizes de Contribuição

- Sempre verifique se já existe uma issue aberta relacionada à sua contribuição
- Para mudanças grandes, abra uma issue antes para discussão
- Mantenha o código limpo, legível e escalável
- Siga o padrão de organização já definido no projeto
- Evite dependências desnecessárias

## Padrões de Código

- Sempre utilize indentação com 2 espaços (tabs) de um padrão
- Utilize TypeScript sempre que possível
- Prefira funções puras e reutilizáveis
- Separe responsabilidades (UI, lógica, serviços, etc)
- Nomeie variáveis e funções de forma clara
- Utilize aliases (@/) para imports
